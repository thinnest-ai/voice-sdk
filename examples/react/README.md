# React Example — Vite + TypeScript

A React app with a voice agent component using `@thinnest-ai/voice-sdk`.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Setup

1. Edit `src/App.tsx` — replace `YOUR_API_KEY` and `YOUR_AGENT_ID` with your credentials
2. Get credentials from [thinnest.ai](https://thinnest.ai) → Agent Studio → Deploy → API tab

## What's Included

- Start/end voice calls with one click
- Real-time transcripts (user + agent)
- Mute/unmute toggle
- Call duration timer
- Connection status indicator
